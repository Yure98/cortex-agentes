# Checklist de documentos: auxílio-acidente urbano, avulso e doméstico

Priorize os itens marcados como essenciais para a análise documental prévia da Portaria
Conjunta MPS/INSS nº 15/2026. Um requerimento sem eles corre risco de indeferimento sem
perícia.

## Identificação
- [ ] RG e CPF
- [ ] Comprovante de residência

## Qualidade de segurado e enquadramento
- [ ] CNIS atualizado
- [ ] CTPS física, se houver período não lançado no CNIS
- [ ] Registro sindical, se avulso
- [ ] Contrato de trabalho doméstico, se doméstico, com atenção à data do evento (a partir de
      01/06/2015)
- [ ] Se contribuinte individual hoje: documentação do vínculo empregatício anterior e data de
      rescisão, para testar a exceção do período de graça

## Nexo técnico
- [ ] CAT, se emitida (essencial quando existir)
- [ ] Se não há CAT: registro alternativo (boletim de ocorrência, prontuário de urgência,
      declaração de testemunha)
- [ ] PPP, se doença ocupacional
- [ ] PCMSO e PGR da empresa, se disponíveis
- [ ] Laudos ambientais, se disponíveis

## Prova médica da sequela (essencial)
- [ ] Relatório médico recente descrevendo diagnóstico, consolidação e repercussão funcional
- [ ] Exames de imagem relacionados
- [ ] Prontuário de atendimento do evento agudo, se acidente típico
- [ ] Histórico completo de tratamento

## Histórico de benefícios
- [ ] Extrato de auxílio-doença anterior, com datas de início e cessação
- [ ] Carta de indeferimento anterior, se houver
- [ ] Extrato de outros benefícios em manutenção, para análise de cumulação

## Complementares
- [ ] Fotos do local ou do equipamento envolvido, se úteis
- [ ] Testemunhas identificadas, com contato

Consulte `references/11-fase-administrativa.md` para o fluxo completo do requerimento.
